# Bayerns Regierungsbezirke – Lernwebsite

Eine einfache Lernwebsite für ein Uni-Seminar. Sie besteht aus zwei Seiten:

1. **Infoseite** (`index.html`): Grundlagen und eine interaktive Karte – ein Klick auf einen Regierungsbezirk zeigt Regierungssitz, Fläche, Einwohner und wichtige Fakten
2. **Quizseite** (`quiz.html`): 10 Multiple-Choice-Fragen, die die Informationen abfragen

## Dateien

- `index.html` – Infoseite (Startseite)
- `quiz.html` – Quiz
- `style.css` – gemeinsames Design beider Seiten

## Veröffentlichung

Die Seite wird über GitHub Pages veröffentlicht (Settings → Pages).

## Quellen

- Einwohnerzahlen: Bayerisches Landesamt für Statistik, Stand 31.12.2025 (gerundet)
- Karte: eigene, vereinfachte Darstellung (direkt als SVG in `index.html` eingebaut, keine Bilddatei nötig)

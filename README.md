# Bayerns Regierungsbezirke – Lernwebsite

Eine einfache Lernwebsite für ein Uni-Seminar. Sie besteht aus zwei Seiten:

1. **Infoseite** (`index.html`): interaktive Lernbausteine zum Aufbau Bayerns (Ebenen-Treppe, Klapp-Karten, Himmelsrichtungs-Kompass), eine interaktive Karte mit Infos zu jedem Regierungsbezirk und eine sortierbare Vergleichstabelle. Für jeden gelesenen Bezirk gibt es einen Stempel im Entdecker-Pass.
2. **Quizseite** (`quiz.html`): 10 Multiple-Choice-Fragen. Das Quiz wird erst freigeschaltet, wenn alle 7 Stempel gesammelt sind. Am Ende gibt es eine Auswertung in vier Stufen (100 %, ab 80 %, ab 50 %, unter 50 %) und eine Übersicht aller Antworten.

## Dateien

- `index.html` – Infoseite (Startseite)
- `quiz.html` – Quiz
- `style.css` – gemeinsames Design beider Seiten

## Veröffentlichung

Die Seite wird über GitHub Pages veröffentlicht (Settings → Pages).

## Quellen

- Einwohnerzahlen: Bayerisches Landesamt für Statistik, Stand 31.12.2025 (gerundet)
- Karte und Symbole: eigene, vereinfachte Darstellung (direkt als SVG eingebaut, keine Bilddateien nötig)

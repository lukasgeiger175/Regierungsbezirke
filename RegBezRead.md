# Bayerns Regierungsbezirke – Lernwebsite

Eine einfache Lernwebsite für ein Uni-Seminar. Sie besteht aus zwei Teilen:

1. **Informationen** zu den sieben Regierungsbezirken Bayerns (Regierungssitz, Fläche, Einwohner, wichtige Fakten)
2. **Quiz** mit 10 Multiple-Choice-Fragen, das die Informationen abfragt

## Aufbau

Die gesamte Website steckt in einer einzigen Datei: `index.html` (Inhalt, Design und Quiz).

## Veröffentlichung

Die Seite wird über GitHub Pages veröffentlicht (Settings → Pages).

## Quellen

Einwohnerzahlen: Bayerisches Landesamt für Statistik, Stand 31.12.2025 (gerundet).
